PT GALERY PRIMA INDONESIA — WEBSITE

Isi:
- index.html : halaman website responsif
- assets/ : logo dan foto proyek yang diberikan

Cara melihat:
1. Ekstrak ZIP.
2. Buka index.html di browser untuk pratinjau lokal.

Cara menerbitkan gratis:
1. Buat akun GitHub.
2. Buat repository publik bernama galery-prima-website.
3. Unggah index.html dan folder assets (struktur folder harus tetap).
4. Buka Settings > Pages.
5. Pada Build and deployment pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses selesai. GitHub akan memberikan alamat website gratis.
